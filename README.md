## ⚡ Автоматические инженерные исправления «под капотом»

1. **Защита от конфликта хуков урона**:
   - `minirework.ini`: принудительно задаются флаги `RegenMod=0`, `MedToolsMod=0`, `StealRebalance=1`, `FO2_ECCO=1`. Формула урона отдается выверенному движку EcCo, а тактические механики — MiniRework.
   - `fo2tweaks.ini`: отключены дублирующие модули `healing_revision=0`, `damage_mod=0`, `ap_rollover=0`, `max_knockback=-1`, `molotov_fire=0`.
2. **Память и права скриптов (`ddraw.ini`)**:
   - `AllowUnsafeScripting=2`: полный доступ для кастомных боевых скриптов MiniRework без зависаний.
   - `SpeedInterfaceCounterAnims=2`: мгновенный отклик счетчиков и ходов.
   - `ExtraMemory=1`: расширенный пул динамической памяти для сотен глобальных таймеров.
3. **Патч Large Address Aware (LAA 4GB)**:
   - Инсталлятор автоматически выставляет PE-флаг `0x0020` в заголовке `fallout2.exe`. Это снимает 32-битное ограничение в 2 ГБ и предотвращает краши памяти в густонаселенных городах (Нью-Рино, Сан-Франциско).
4. **Строгий порядок загрузки (`mods_order.txt`)**:
   - Гарантированная последовательность инициализации: `RPU -> Translations -> EcCo -> EcCo HF1 -> THAT Patch -> MiniRework -> FO2Tweaks -> VOCK`.

## 🚀 Как запустить инсталлятор

1. Запустите файл **`Run_Installer.bat`** (или `python installer_gui.py`).
2. Укажите папку с установленной оригинальной игрой (Steam / GOG / 1.02d).
3. Выберите нужный пресет («Gameplay Ultimate», «HD Visual Dustlight» или «Dual Profile»).
4. Нажмите **«Собрать и установить сборку»**.

После завершения перейдите в целевую папку и используйте единый лаунчер **`launcher.py`** для комфортного запуска нужного профиля, настройки разрешения экрана и доступа к сейвам!
