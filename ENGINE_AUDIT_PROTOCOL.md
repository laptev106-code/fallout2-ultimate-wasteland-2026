## 1. СИСТЕМНАЯ МОДЕЛЬ ДВИЖКА И ВЕКТОРЫ КОНФЛИКТОВ

Движок классического *Fallout 2* с надстройками **sfall v4.4.8 (DirectX 9)** и **Community Edition (SDL2 + Dustlight v0.9.4-beta)** представляет собой многослойную виртуальную файловую систему (VFS), исполняющую байткод в виртуальной машине (FOVM). Любой мод — это наложение слоев данных на базовую игру. 

Конфликты в Fallout 2 возникают строго в 7 точках отказа:
1. **VFS Collision (Коллизия виртуальной файловой системы):** Неправильный порядок загрузки архивов `.dat` и папок в `mods_order.txt`, приводящий к затиранию новых скриптов старыми или перезаписи локализации.
2. **Registry Desync (Рассинхрон таблиц реестров LST):** Несовпадение индексов в `heads.lst`, `scripts.lst`, `city.txt`, `items.lst`, `critters.lst`. Вызывает показ чужих лиц, спавн не тех предметов или краш с ошибкой `Not found in LST`.
3. **Dialogue Tag & Lip-Sync Breakdown (Поломка диалогов и мимики):** Несоответствие тегов анимации рта `{TAG}` в `.msg` файлах скомпилированным процедурам `.int`. Вызывает ступор мимики, немоту говорящих голов или прерывание диалогов с ошибкой `Error: [text not found]`.
4. **Scancode Collision (Конфликт горячих клавиш):** Назначение одного DX-сканкода (например, `W`, `Tab`, `Caps Lock`, `F1-F12`) в разных `.ini` файлах на взаимоисключающие действия.
5. **Memory Patching Hazard (Опасные инъекции в память):** Прямые вызовы `write_byte` / `write_int` по жестким адресам Win32 x86 (0x400000+), приводящие к мгновенному падению (Access Violation) в альтернативных движках (Community Edition) или на новых версиях sfall.
6. **GVAR / LVAR Corruption (Загрязнение глобальных переменных):** Использование одинаковых индексов GVAR разными модами, ломающее счетчики квестов и триггеры концовок.
7. **Resolution / Aspect Ratio Clamp (Клиппинг интерфейса):** Использование элементов оформления, рассчитанных на 640x480, при включенном масштабировании `SCALE_2X=1` или высоких разрешениях 1080p/1440p/4K.

## 2. ЧЕК-ЛИСТ УРОВНЯ 0: ИНФРАСТРУКТУРА И КОНФИГУРАЦИЯ

- [x] **LAA (Large Address Aware) флаг:** Убедиться, что бинарники `fallout2.exe` и `dustlight.exe` имеют выставленный бит LAA (доступ к 4 ГБ виртуального адресного пространства вместо 2 ГБ).
- [x] **DirectX / Direct3D режим:**
  - В `Fallout2_Gameplay\ddraw.ini` выставлен `GraphicsMode=2` (Direct3D 9 с поддержкой шейдеров).
  - В `Fallout2_Gameplay\f2_res.ini` выставлен `GRAPHICS_MODE=0` (управление окном передано sfall).
- [x] **Снятие лимита 13 лет:** Параметр `TimeLimit=-3` активирован во всех профилях.
- [x] **Разрешения экрана и 2X масштаб:**
  - `SCR_WIDTH` и `SCR_HEIGHT` не ниже 890x720 (стандарт: 1920x1080 для Gameplay, 2560x1440 для HD).
  - `SCALE_2X=1` активен для комфортного чтения интерфейса на современных мониторах.
- [x] **Музыкальное сопровождение:** `EnableMusicInDialogue=1` включен (устранена тишина при вызове голов).
- [x] **Скриптовые разрешения:** `AllowUnsafeScripting=2` включен в `ddraw.ini` для работы интерфейсных плагинов (`InventoryFilter`).

## 4. ЧЕК-ЛИСТ УРОВНЯ 2: СКРИПТОВАЯ ЦЕЛОСТНОСТЬ И ИНТЕРФЕЙСЫ

- [x] **Валидация реестра `scripts.lst`:**
  - Каждый вызываемый скрипт криттера, предмета или карты обязан присутствовать в `scripts/scripts.lst`.
  - Отсутствие висячих ссылок (dangling scripts).
- [x] **Проверка GVAR (Глобальных переменных):**
  - Все переменные, используемые в аддонах (таймеры Пип-Боя: `GVAR_STILL_STATUS`, `GVAR_SLAUGHTER_SLAG_TIME`, `GVAR_NEW_RENO_GUARD_ASSIGNMENT`), обязаны быть задекларированы в `data/quests.txt` или заголовках RPU.
  - Никакой мод не должен перетирать системные переменные движка без сброса флагов.
- [x] **Безопасность опкодов sfall:**
  - Скрипты, использующие хуки `HOOK_GAMEMODECHANGE`, `HOOK_RESTTIMER`, `HOOK_SETGLOBALVAR`, обязаны предварительно проверять `game_loaded`.

## 5. ЧЕК-ЛИСТ УРОВНЯ 3: ДИАЛОГОВАЯ И ТЕКСТОВАЯ ПОДСИСТЕМА

- [x] **Сквозная проверка номеров строк `mstr(id)`:**
  - Для каждого `.int` скрипта все запрашиваемые строки обязаны присутствовать в соответствующем `.msg` файле папки `text/russian/dialog/`.
  - Полный запрет на ошибки вида `Error: [text not found]`.
- [x] **Липсинк и маркеры мимики говорящих голов:**
  - Все персонажи, имеющие 3D-головы, обязаны иметь маркеры анимации во втором поле `{TAG}` (например, `{240}{SMIT1}{...}` для Смитти, `{117}{TROY1}{...}` для Троя, `{154}{MIRIA1}{...}` для Мирии).
  - Проверка отсутствия пустых тегов `{}` в диалогах персонажей с говорящими головами.
- [x] **Кодировка текста:** Все русские файлы обязаны иметь строгую кодировку **CP1251 (Windows-1251)** без UTF-8 BOM, так как оригинальный шрифт движка Fallout 2 рендерит кириллицу строго по таблице CP1251.

## 7. ЧЕК-ЛИСТ УРОВНЯ 5: МАТРИЦА ГОРЯЧИХ КЛАВИШ (SCANCODE MATRIX)

- [x] **Изоляция сканкодов ввода:**
  - Клавиша `W` (scancode 17): зарезервирована для `InventoryFilter` (переключение контейнера). В `fo2tweaks.ini` параметр `worldmap_key` обязан быть равен `0`.
  - Клавиша `Q` (scancode 16): зарезервирована для `InventoryFilter` (переключение инвентаря игрока).
  - Клавиша `J`: назначена на вызов экрана помощи по клавишам (`J=F1` в `fo2tweaks.ini`).
  - Клавиша `Caps Lock` (scancode 58) / `Tab` (scancode 15): зарезервирована для подсветки предметов (`Highlighting`).
  - Клавиши `F5` / `F8`: переназначены на современный быстрый сейв / быструю загрузку (`F5=F6`, `F8=F7`).
  - Клавиша `V`: переключение отображения полосок здоровья (`hp_over_head`).

## 9. ПРОТОКОЛ СКВОЗНОГО БЕТА-ТЕСТИРОВАНИЯ (IN-GAME SCENARIOS)

1. **Сценарий «Храм Испытаний и Аройо»:**
   - Старт новой игры. Проверка выбора внешности героя в стартовом меню (Hero Appearance).
   - Диалог с Клинтом: проверка говорящей головы Клинта, мимики рта и русского текста.
   - Завершение Храма: проверка отсутствия крэшей при выходе в деревню.
   - Диалоги со Старейшей и Хакунином: проверка отображения классических голов.
2. **Сценарий «Кламат»:**
   - Вход в город: проверка освещения (`min_light_level=40`).
   - Разговор с Суликом: проверка смены спрайта при надевании кожаной куртки (`npc_armor`).
   - Пастбище Торра и братья Дантоны: сдача квеста без применения оружия.
   - Самогонный куб Бобби: появление стилизованной памятки таймера в Pip-Boy.
3. **Сценарий «Ден (Притон)»:**
   - Смитти: проверка говорящей головы кузнеца Смитти, мимики и текста.
   - Проверка диалога покупки Хайвеймена и установки регулятора топлива.
   - Метцгер и Лара: проверка говорящих голов работорговцев.
4. **Сценарий «Модок»:**
   - Разговор с Мирией: проверка мимики и диалоговой ветки.
   - Квест Карла: активация таймера в Pip-Boy.
   - Часы Корнелиуса: мирное разрешение конфликта Корнелиуса и Фаррела.
5. **Сценарий «Город Убежища и Гекко»:**
   - Доктор Трой: проверка говорящей головы и операции на сердце Кэссиди.
   - Реактор Гекко: проверка оптимизации охлаждения Фестусом без застреваний.
   - Скитер: апгрейд оружия без зависания инвентаря.
6. **Сценарий «Бой и инвентарь»:**
   - Открытие инвентаря: проверка 8 слотов (`ExpandInventory=1`) и фильтров (`InventoryFilter`).
   - Стрельба очередями и взрыв гранат: проверка физики рикошетов (`MissToHit`) и выбивания оружия (`CripplingExplosions`).
   - Сбор лута: проверка аккуратного сохранения вещей в пепле (`no_drop_items_on_death=1`).
