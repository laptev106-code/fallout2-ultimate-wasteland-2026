# Wasteland Voices // Живые Голоса Пустоши (v1.0.0)

Автономный нарративный модуль для Fallout 2 (RPU 2.4.x / Ultimate Wasteland Edition).

---

## 1. Описание

**Wasteland Voices** возвращает в Пустошь атмосферу живого мира конца 90-х годов по каноничным стандартам Black Isle Studios (Тим Кейн, Крис Авеллон, Марк О'Грин). Напарники больше не ходят за игроком как безмолвные манекены — они комментируют знаковые города и события, а мир остро реагирует на силовую броню, обнаженное тяжелое оружие, мутантов в отряде и глупость Избранного.

---

## 2. Двухконтурная архитектура

1. **Контур 1 (Core RPU):**
   - 12 каноничных поселений (Арройо, Кламат, Ден, Модок, Город Убежища, Гекко, Реддинг, Брокен Хиллс, Нью-Рено, НКР, Сан-Франциско, Наварро).
   - Спутники: Сулик, Кэссиди, Вик, Маркус, Горис.
   - Реактивность на силовую броню, тяжелые пушки, мутантов и низкий интеллект (`IN < 4`).
   - Совместим с любой базовой установкой Fallout 2 + RPU.

2. **Контур 2 (Extended Wasteland):**
   - Расширенные локации: Аббатство (The Abbey), EPA (экологическое агентство), Деревня дикарей (Primitive Tribe), Бункер 21, Скрапхип.
   - Расширенные спутницы: Прокачиваемая Мирия (Enhanced Miria), Сери, Лара, Сестра Сулика.
   - Реакции на тяжелые бои и нехватку патронов при балансе EcCo.
   - Безопасное автоопределение карт (`cur_map_index`): не вызывает вылетов при отсутствии карт в игре.

---

## 3. Установка

1. Скопируйте `wasteland_voices.dat` и `wasteland_voices.ini` в директорию `mods/` вашей игры.
2. Откройте `mods/mods_order.txt` и добавьте строку:
   ```
   wasteland_voices.dat
   ```
3. Настройки частоты и шансов регулируются в файле `mods/wasteland_voices.ini`.

---

## 4. Сборка из исходников

Для сборки мода в автономный DAT-архив запустите:
```bash
python build.py
```
Для автоматической компиляции и развертывания в игровые профили:
```bash
python build.py --deploy
```
