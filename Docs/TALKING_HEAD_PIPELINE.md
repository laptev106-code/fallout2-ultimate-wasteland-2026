# РУКОВОДСТВО ПО СОЗДАНИЮ ГОВОРЯЩИХ ГОЛОВ (TALKING HEADS) ДЛЯ FALLOUT 2

Настоящий регламент определяет полный замкнутый цикл производства аутентичных 32-битных анимированных говорящих голов для Fallout 2 (Restoration Project Updated + sFall 4.5.1+).

---

## 1. Архитектурные требования движка Fallout 2 (sFall 32-Bit Mode)

### 1.1. Параметры рендера
В `ddraw.ini` должен быть включен 32-битный графический режим:
```ini
[Graphics]
Use32BitHeadGraphics=1
```
Это позволяет использовать покадровые PNG-файлы (RGBA 32-bit с альфа-каналом) вместо устаревшей 8-битной палитры Fallout (256 цветов FRM).

### 1.2. Структура каталогов персонажа
В директории `art/heads/<char_name>/` (или внутри VFS `.dat` архива) размещаются подкаталоги состояний:
- `np/` — **Neutral Phonemes**: циклическая артикуляция губ при нейтральном разговоре (15–30 кадров).
- `nf1/`, `nf2/` — **Neutral Fidgets**: моргание, микродвижения глаз и наклон головы в режиме ожидания ответа (20–40 кадров).
- `bp/` — **Bad Phonemes**: раздраженная, агрессивная речь с нахмуренными бровями.
- `bf1/` — **Bad Fidgets**: агрессивный режим ожидания (тяжелый взгляд, оскал, раздраженное моргание).
- `gp/` — **Good Phonemes**: доброжелательная, расслабленная речь.
- `gf1/` — **Good Fidgets**: расслабленное ожидание с легкой улыбкой.
- Опционально `na/` — Neutral to Anger: переходная анимация реакции.

Формат именования кадров: строго `0.png`, `1.png`, `2.png`, ... без ведущих нулей.

### 1.3. Регистрация в `heads.lst`
Список голов `art/heads/heads.lst` в sFall расширяем без ограничений (начиная со строк 248+):
```text
kcbob, 1, 2, 1
```
Синтаксис: `<имя_папки>, <число_fidget_good>, <число_fidget_neutral>, <число_fidget_bad>`.

## 2. Пошаговый производственный конвейер

### Шаг 1: Концепт-арт и базовый бюст (Black Isle Style)
1. **Каноничный стиль 1998 года**:
   - Техника: глиняная скульптура (стиль Скотта Родденберри), оцифрованная через Silicon Graphics.
   - Постановка света: контрастный трехточечный студийный свет, жесткие тени, холодные тона пустошей.
   - Ракурс: легкие три четверти или прямой анфас, плечи и ключицы в кадре.
   - Одежда: засаленная кожа, пыльная шерсть, металлические заклепки или рабочая роба.
2. **Промпт-шаблон**:
   `"Original 1998 Fallout 2 talking head style, clay sculpt bust by Scott Roddenberry, textured digital render, wasteland dirty post-apocalyptic survivor [DESCRIPTION], sharp studio dramatic rim lighting, dark atmospheric fallout background, 4:3 portrait aspect ratio, photorealistic clay model"`

### Шаг 2: Препроцессинг и стабилизация фона
1. Кадрирование исходника в пропорции 4:3 (400x300 px или 320x240 px).
2. Выравнивание уровня глаз по строго горизонтальной линии.
3. Отделение персонажа от фона (Alpha Matte):
   - В движке Fallout фон говорящей головы обязан быть 100% статичным. Любые микроколебания фона при анимации создают брак ("эффект аквариума").
   - Фон вырезается и заменяется статичной подложкой локации (интерьер бара, пустошь, бункер).

### Шаг 3: Анимация мимики через Browser Skill (`bsk`) и LivePortrait
1. **Почему LivePortrait / TPS**:
   - Диффузионные видеосети (Sora, Runway, Kling) перерисовывают текстуру кожи в каждом кадре ("кипящий пластилин").
   - LivePortrait / Thin-Plate Spline берет статичную картинку и деформирует только мимические узлы (губы, веки, брови), сохраняя геометрию и текстуру лица неизменной на 100%.
2. **Управление через Chrome (`bsk`)**:
   - `bsk` открывает веб-интерфейс LivePortrait (HuggingFace / Replicate / локальный Gradio).
   - Загружает подготовленный `base_bust.png`.
   - Поочередно прогоняет короткие (2–3 сек) управляющие видео:
     - `donor_talk_neutral.mp4` -> `out_np.mp4`
     - `donor_idle_blink.mp4` -> `out_nf1.mp4`
     - `donor_talk_angry.mp4` -> `out_bp.mp4`
     - `donor_idle_angry.mp4` -> `out_bf1.mp4`
   - Скачивает результаты в `tools/output_videos/`.

### Шаг 4: Нарезка и сборка секвенций (FFmpeg + Python)
1. Извлечение кадров через FFmpeg:
   ```bash
   ffmpeg -i out_np.mp4 -vf "fps=18,scale=400:300" np/%d.png
   ```
2. Python-скрипт нормализации:
   - Переименовывает кадры от `0.png`.
   - Запекает статичный фон под маску прозрачности.
   - Оптимизирует PNG без потери цветности.

### Шаг 5: Интеграция в движок и скриптинг диалога
1. Добавление записи в `art/heads/heads.lst`:
   - Определяется новый индекс (например, 248).
2. Модификация диалогового скрипта персонажа (`scripts_src/<city>/<script>.ssl`):
   - Замена вызова диалога на `start_gdialog(NAME, self_obj, 4, HEAD_ID, BACKGROUND_ID)`.
   - Использование стандартных макросов Fallout 2 (`gSay_Start`, `gSay_End`).
3. Компиляция:
   ```cmd
   compile.exe -p <script>.ssl
   ```
   Полученный `.int` помещается в `mods/rpu_russian_uncensored.dat/scripts/`.

### Шаг 6: Замкнутое тестирование (Closed-Loop)
1. Запуск через `Fallout2_NextGen_Launcher.exe` или `fallout2.exe`.
2. Вход в локацию персонажа, инициация диалога.
3. Контроль параметров:
   - Отсутствие артефактов на границе альфа-канала (черные ободки).
   - Адекватность липсинка (движение губ при появлении текста).
   - Плавность перехода в режим ожидания (fidget).
